LivePorter — iPhone 实况照片搬运与浏览（Windows 绿色版）
========================================================

系统要求
--------
- Windows 10 1809 及以上（64 位）
- Microsoft Edge WebView2 运行时（Win10/11 一般已自带；缺失会白屏，见下）

怎么用
------
1. 把整个 LivePorter 文件夹解压到任意位置（桌面、D 盘都行）。
   注意：不要只把 LivePorter.exe 单独拿出来，resources 子目录要跟它在一起。
2. 双击 LivePorter.exe。免安装、免管理员、不写注册表。
3. 点“打开库”，选一个硬盘目录作为库；之后导入的原图与原视频都放在这个目录里。
4. 插上 iPhone，点“从 iPhone 导入”。

首次运行提示
------------
- 可能被 SmartScreen 拦截（本程序未做代码签名）：点“更多信息”→“仍要运行”。
- 若白屏，说明缺少 WebView2 运行时。到微软官网搜索 “WebView2 Runtime”
  下载安装（Evergreen Bootstrapper）后重开即可。

导入 iPhone 前必看
------------------
- iPhone 必须设为“保留原件”：
  设置 → 照片 → 拉到最下面 → “传输到 Mac 或 PC” = “保留原件”。
  若设为“自动”，iOS 会边传边把 HEIC 转成 JPG，速度慢约 17 倍且格式被转码。
  改完设置后需要拔下数据线再重新插上才生效。
- iCloud“优化 iPhone 储存空间”可能导致手机上只有缩略图而非原件。
  本版本不会自动阻止导入，只会在导入后把明显偏小的条目标记为“疑似副本”。
  如果不确定，导入时勾选“原件可能不在手机”获得更多提示。

关于库目录
----------
- 你选的目录就是库本身：原图、原视频、缩略图、预览片都在里面。
- 其中 .lpm 子目录只是索引与缓存，可以随时删除，原始文件不受影响；
  删除后重新“重建索引”即可。
- “删除选中”会把文件移到 Windows 回收站（可在回收站还原）。
  注意：回收站容量有限，超出配额的大文件可能被直接永久删除。
